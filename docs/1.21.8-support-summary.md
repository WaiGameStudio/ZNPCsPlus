# ZNPCsPlus 1.21.8 支持总结

## ✅ 验证结果

**ZNPCsPlus 2.1.0 已完全支持 Minecraft 1.21.8**

构建时间：2026-08-17  
构建产物：`plugin/build/libs/ZNPCsPlus-2.1.0.jar` (6.7MB)

## 🔧 技术实现

### 1. PacketEvents 支持
- **版本**: 2.13.0
- **协议支持**: 26.2 (对应 Minecraft 1.21.8)
- **依赖配置**: `plugin/build.gradle:22`

### 2. Packet Factory 架构
- **使用的 Factory**: `V1_21_3PacketFactory`
- **工作原理**: 智能版本回退机制
  - 1.21.8 自动回退到 1.21.3 实现
  - 共享相同的数据包结构
- **文件位置**: `plugin/src/main/java/lol/pyr/znpcsplus/packets/V1_21_3PacketFactory.java`

### 3. STATUS 阶段修复 (1.21.8 特有)
**问题**: 1.21.8 在服务器列表 ping 时 `disconnect` 包编码错误

**解决方案**:
- `StatusPhaseExceptionHandler`: Netty handler 拦截 STATUS 阶段异常
- `StatusPhaseInjector`: 自动注入到所有服务器连接
- **详细文档**: `docs/1.21.8-status-phase-fix.md`

**注入位置**: `ZNpcsPlus.onEnable()` → `packetEvents.init()` 之后

### 4. 实体属性更新
- ✅ Sulfur Cube 实体及其属性
- ✅ EncodedLongProperty (协议 26.1+)
- ✅ StriderShakingProperty (协议 26.1+)
- ✅ 肩膀鹦鹉元数据修复 (1.21.9+)

## 🔍 架构优势

### 智能版本回退
不需要为每个小版本创建新的 Packet Factory：
- **定义的版本**: 1.8, 1.17, 1.19.3, 1.20.2, 1.21.3
- **支持的版本**: 所有 1.8 - 1.21.11

### 非侵入式修复
STATUS 阶段修复通过 Netty pipeline 注入：
- 不修改 PacketEvents 源码
- 不影响旧版本兼容性
- 清晰的注入/卸载生命周期
