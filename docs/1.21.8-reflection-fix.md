# 1.21.8 反射策略修复

## 问题描述

在 1.21.8 版本启动时，`StatusPhaseInjector` 无法通过反射获取 `ServerConnection` 对象：

```
[ZNPCsPlus] Failed to inject STATUS phase handler - server list ping errors may appear in logs
java.lang.NoSuchMethodException: ServerConnection getter not found
        at lol.pyr.znpcsplus.util.StatusPhaseInjector.getServerConnection(StatusPhaseInjector.java:98)
```

## 根本原因

Minecraft 1.21.8 的 `MinecraftServer` 类结构发生变化：
- **旧版本**: `ServerConnection` 通过公开的 getter 方法暴露
- **1.21.8**: `ServerConnection` 可能变为私有字段，没有 getter 方法

原有实现只尝试查找 getter 方法：
```java
// 旧代码 - 只查找方法
for (Method method : minecraftServer.getClass().getDeclaredMethods()) {
    if (method.getReturnType().getSimpleName().equals("ServerConnection")) {
        method.setAccessible(true);
        return method.invoke(minecraftServer);
    }
}
```

## 解决方案

实现三层渐进式反射查找策略，确保跨版本兼容性。

### Strategy 1: Getter 方法查找（兼容旧版本）

```java
for (Method method : minecraftServer.getClass().getDeclaredMethods()) {
    if (method.getParameterCount() == 0 &&
        method.getReturnType().getSimpleName().equals("ServerConnection")) {
        method.setAccessible(true);
        return method.invoke(minecraftServer);
    }
}
```

**适用版本**: 1.8 - 1.21.7  
**优先级**: 最高（性能最好，符合 Java Bean 规范）

### Strategy 2: 直接字段访问（1.21.8+）

```java
for (Field field : minecraftServer.getClass().getDeclaredFields()) {
    if (field.getType().getSimpleName().equals("ServerConnection")) {
        field.setAccessible(true);
        return field.get(minecraftServer);
    }
}
```

**适用版本**: 1.21.8+  
**触发条件**: Strategy 1 失败时  
**优点**: 绕过封装变化，直接访问字段

### Strategy 3: 父类字段遍历（继承结构变化）

```java
Class<?> currentClass = minecraftServer.getClass();
while (currentClass != null) {
    for (Field field : currentClass.getDeclaredFields()) {
        if (field.getType().getSimpleName().equals("ServerConnection")) {
            field.setAccessible(true);
            return field.get(minecraftServer);
        }
    }
    currentClass = currentClass.getSuperclass();
}
```

**适用版本**: 未来版本（防御性编程）  
**触发条件**: Strategy 1 和 2 都失败时  
**优点**: 处理 `ServerConnection` 被移到父类的情况

## 完整实现

**文件**: `plugin/src/main/java/lol/pyr/znpcsplus/util/StatusPhaseInjector.java:93-125`

```java
private Object getServerConnection(Object minecraftServer) throws Exception {
    // Strategy 1: Try getter methods
    for (Method method : minecraftServer.getClass().getDeclaredMethods()) {
        if (method.getParameterCount() == 0 &&
            method.getReturnType().getSimpleName().equals("ServerConnection")) {
            method.setAccessible(true);
            return method.invoke(minecraftServer);
        }
    }

    // Strategy 2: Try direct field access (1.21.8+)
    for (Field field : minecraftServer.getClass().getDeclaredFields()) {
        if (field.getType().getSimpleName().equals("ServerConnection")) {
            field.setAccessible(true);
            return field.get(minecraftServer);
        }
    }

    // Strategy 3: Try fields in superclasses
    Class<?> currentClass = minecraftServer.getClass();
    while (currentClass != null) {
        for (Field field : currentClass.getDeclaredFields()) {
            if (field.getType().getSimpleName().equals("ServerConnection")) {
                field.setAccessible(true);
                return field.get(minecraftServer);
            }
        }
        currentClass = currentClass.getSuperclass();
    }

    throw new NoSuchMethodException("ServerConnection getter/field not found in MinecraftServer");
}
```

## 技术优势

### 1. 渐进式降级
- 优先使用标准方法（getter）
- 失败后自动尝试字段访问
- 兜底策略处理继承结构变化

### 2. 跨版本兼容
- **向后兼容**: 旧版本仍使用 getter 方法
- **向前兼容**: 新版本自动切换到字段访问
- **未来兼容**: 父类遍历处理未知变化

### 3. 零配置
- 无需版本号硬编码
- 自动适应 NMS 结构变化
- 失败时提供清晰的错误信息
